# Dataset Information and License

## Dataset Name

Chest X-Ray Images (Pneumonia)

## Source

- Kaggle: https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia
- Original research dataset: https://doi.org/10.17632/rscbjbr9sj.3
- Dataset uploader: Paul Mooney
- Original research authors: Daniel S. Kermany, Kang Zhang, and Michael Goldbaum

## Description

This dataset contains chest X-ray images organized into two classes:

- NORMAL
- PNEUMONIA

It is used in this project to evaluate Vision Transformer (ViT) image classification, CLAHE preprocessing, raw/CLAHE fusion, and test-time augmentation.
